# Bavet

## Structure

Monorepo at `apps/` with npm workspaces (`apps/package.json`).

| Workspace | Stack | Entrypoint |
|-----------|-------|------------|
| `apps/web` | React 18 + Vite 7 + Tailwind 3 + shadcn/ui (new-york, JSX) | `apps/web/src/main.jsx` |
| `apps/pocketbase` | PocketBase 0.27 (Go binary) | `apps/pocketbase/pocketbase.exe` |

Root `G:\acer\Desktop\bavet` has no package.json. **Run all npm commands from `apps/`.**

## Commands (from `apps/`)

```bash
npm install              # install all workspaces
npm run dev              # Vite (port 3000, all interfaces) + PocketBase (port 8090)
npm run build            # Vite build for web only
npm run lint             # eslint . --quiet (no config, no-op)
npm run start            # PocketBase server only
```

Single workspace: `npm run dev --prefix apps/web` or `--prefix apps/pocketbase`.

## Conventions

- **No TypeScript** — all `.jsx`/`.js`. shadcn `"tsx": false`.
- **Alias** `@/` → `apps/web/src/` (vite.config.js resolve alias).
- **CSS** — Tailwind with CSS variables. Use `cn()` from `@/lib/utils`.
- **PB client** — singleton from `@/lib/pocketbaseClient`. URL from `VITE_POCKETBASE_URL`, defaults to `http://localhost:8090`.
- **Auth** — `AuthContext` at `@/contexts/AuthContext.jsx`. Role-based routing via `ProtectedRoute` (`admin` → `/admin/*`, `client` → `/client/*`).
  - `signup()` auto-creates a `clients` record. `createAdminAccount()` checks `VITE_ADMIN_SECRET` (dev value at `apps/web/.env`, tracked in git).
  - Users collection has `role` field (`admin` | `client`), defaulted to `client` via `pb_hooks/set-default-role.pb.js`.
- **Currency** — `formatCurrency()` uses `fr-TN` locale / `TND` (Tunisian dinar). Invoice labels are in French.
- **No tests** exist.
- **Generated files** — `pb_migrations/` is auto-generated by PocketBase, not for manual editing.

## PocketBase

- **Superadmin:** `admin@bavet.local` / `Admin123!` (dev only).
  - Auth endpoint: `api/collections/_superusers/auth-with-password` (PB 0.27 change).
- Schema scripts at `apps/` (run as `node <script>.mjs` with PB running):
  - `setup_pb.mjs` — idempotent, **older API** (uses `schema` not `fields`, singular field names like `user`, `client`).
  - `fix_schema.mjs` — **destructive** (drops & recreates), **canonical** (uses `fields`, `userId`/`clientId`/etc. naming).
  - `fix_users.mjs` — sets users collection API rules: public create, admin-only list.
- **PB 0.27 API quirks:**
  - Collection fields use `fields` (not `schema`).
  - Built-in `users` collection ID is `_pb_users_auth_`.
  - Relation fields need actual auto-generated collection ID (e.g. `pbc_12345`). Capture return value of `pb.collections.create()`.
  - Client dashboards/horses/invoices auto-create a missing client record on first load.

### Setting env vars (avoid trailing newlines on Windows)
```powershell
"https://your-tunnel.trycloudflare.com" | Set-Content -NoNewline -Path "$env:TEMP\pburl.txt"
Get-Content "$env:TEMP\pburl.txt" -Raw | vercel env add VITE_POCKETBASE_URL production
```

## Collections

| Collection | Relations |
|-----------|-----------|
| `users` (built-in) | — |
| `clients` | `userId` → `users` |
| `horses` | `clientId` → `clients` |
| `operations` | (service catalog) |
| `medical_records` | `horseId` → `horses` |
| `invoices` | `clientId` → `clients`, `horseId` → `horses` |
| `invoice_items` | `invoiceId` → `invoices`, `operationId` → `operations` |

## Deployment

- **Vercel** — root `vercel.json` orchestrates (`installCommand: "cd apps && npm install"`, points to `apps/web`). Must set `VITE_POCKETBASE_URL` (+ `VITE_ADMIN_SECRET` for admin registration) in Vercel env.
- **Docker** — `apps/pocketbase/Dockerfile` downloads pre-built PB binary, serves on port 8090 with hooks and pb_data.
